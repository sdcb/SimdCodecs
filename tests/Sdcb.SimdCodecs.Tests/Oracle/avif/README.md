# AVIF Oracle and Test Corpus

## Oracle: libavif 1.4.2 + dav1d 1.5.5 (and ffmpeg 8.1.2 cross-check)

AV1 decoding is integer-arithmetic and deterministic across all profiles (0, 1, 2), bit depths (8, 10, 12), chroma subsamplings (4:2:0, 4:2:2, 4:4:4, 4:0:0), Superres and Film Grain synthesis. Every coded image and animation frame's decoded Y / Cb / Cr / Alpha planes must equal the pinned reference decoder bit for bit.

- **Primary plane oracle & benchmark competitor:** `libavif 1.4.2` with `dav1d 1.5.5` (vcpkg `libavif[aom,dav1d,svt]:x64-windows`, black-box DLL via `avif/avif.h` public API only — never read `libavif`, `libaom`, `dav1d` or `SVT-AV1` source).
- **Container & bitstream cross-check:** `ffmpeg 8.1.2` (`libdav1d` + `-bsf:v trace_headers`), used to audit AV1 syntax feature flags and validate ISO/IEC 23008-12 derived items (`iovl`) that `libavif` does not decode.

## Goldens

`Fixtures/avif/avif-golden.tsv` pins, per fixture, the coded dimensions, bit depth, subsampling, alpha presence, frame count and SHA-256 of every frame's decoded Y / Cb / Cr (/ Alpha) planes (each plane prefixed by int32 LE width, height and sample byte size, followed by tightly packed little-endian samples) recorded from `libavif 1.4.2 + dav1d 1.5.5`. Committed digests run without any native oracle installed.

## Test corpus (42 fixtures, 27.85 MB total)

All fixtures are 100% CC0 / Public Domain, generated by `tools/avif-fixtures/` from the CC0 corpus originals (`benchmarks/Sdcb.SimdCodecs.Jpeg.Benchmarks/corpus/manifest.tsv`), original synthetic UI/code screens and deterministic Mandelbrot zoom frames, using `libavif 1.4.2` + `libaom 3.15.3` / `SVT-AV1 4.3.1` as black-box encoders. Download with:

```bash
bash tests/Sdcb.SimdCodecs.Tests/Oracle/avif/fetch.sh
```
