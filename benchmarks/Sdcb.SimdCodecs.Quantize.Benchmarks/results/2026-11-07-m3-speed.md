# M3: quantizer speed, 2026-11-07

The quantizer of f4e20d0 (`baseline`, compiled from `.cache/baseline/`) against this commit's (`ours`), in the same `rd` run; then the PNG encoder's lossy mode end to end (`quality`), and both builds under Mono AOT (browser-wasm).

- Machine: AMD Ryzen 7 5800X (8 cores / 16 threads), Windows 11 10.0.26200, .NET 10.0.11, x64, Vector256 accelerated, Vector512 not; Node.js for the wasm runs.
- pngquant 2.17.0 (September 2021), `--speed 4`.
- Single-threaded throughout: nothing here runs in parallel.

## What changed

- Nearest-entry search: entries stored by coordinate in blocks of four, measured a block at a time (Vector128), outward from the query's lightness; the start found through a 1024-slot lightness table instead of a binary search. Same answer as testing every entry (the nearest, the lowest index among equals), with or without a hint.
- Colour conversion four colours at a time (Vector128); the cube root by two Halley steps instead of four Newton steps, in both paths, bit-identical to each other.
- With more than 2^15 colours, the box split runs on the merged colours (as most k-means iterations already did), and the merging is a hash grouping, done once per palette build rather than once per try.
- The last k-means iterations and the error pass start from each colour's entry in the stage before (the Hamerly separation test and the search bound use it).
- Histogram: key and count side by side, growing from 4 Ki slots instead of 6 MB up front; its entries ordered by a radix sort.
- Mapping: a cache that grows to 2^18 entries with the frame; the cache's empty marker no longer collides with opaque white (every white pixel used to miss); without dithering, missed colours converted in batches; with dithering, diffusion strength computed a row at a time and branch-free rounding.

Tried and dropped: full Hamerly lower bounds (the largest centre move per iteration is about the spacing of a 256-entry palette, so the bound rarely skips, and the two-nearest search costs more: slower); the box split on moved (contiguous) features with child statistics from the buckets (slower than the indexed split).
