# Adam7 decode — 2026-10-28, AMD Ryzen 7 5800X

Same-process A/B against `c621399` (baseline, no Adam7). Command: `LIBPNG_PATH=…/vcpkg/installed/x64-windows/bin/libpng16.dll dotnet run -c Release --project benchmarks/Sdcb.SimdCodecs.Png.Benchmarks -- matrix decode`.

- Adam7: each pass inflated and unfiltered a row at a time in pooled rows, expanded to RGBA and scattered into place (the last pass straight into the destination); `PngReader.Decode` scatters the samples the same way.
- `ReadHeader` refuses image data that would have to inflate more than 1032:1 (a forged header no longer reaches an allocation or an overflow).

### Decode to 8-bit RGBA (in-process medians of 7 interleaved rounds, ms)

`current` = `PngImageDecoder.TryDecodeIntoRgba8` into a caller buffer; `native` = `PngReader.Decode` (samples as stored, no RGBA expansion); ImageSharp = `Image.Load<Rgba32>` + `CopyPixelDataTo`, one thread; libpng = simplified API `png_image_finish_read` to RGBA. Ratios below 1 mean we are faster. Inputs are encoded by ImageSharp (adaptive filters, zlib level 6).
