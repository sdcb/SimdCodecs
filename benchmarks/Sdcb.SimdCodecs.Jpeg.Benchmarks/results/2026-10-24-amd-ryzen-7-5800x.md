# JPEG decode baseline — 2026-10-24 — AMD Ryzen 7 5800X

Single-threaded whole-image decode to RGBA. **Measurement only — no optimisation was done for this baseline.**

Contestants: **Sdcb.SimdCodecs** `JpegDecoder.DecodeTo` into a reused buffer; **libjpeg-turbo 3.2.0** official binary via TurboJPEG 3 (`tj3Decompress8`, `TJPF_RGBA`, reused buffer; defaults = islow IDCT + fancy upsampling); **libjpeg-turbo (fast)** = `TJPARAM_FASTDCT` + `TJPARAM_FASTUPSAMPLE`, for reference; **ImageSharp 3.1.12** (newest release that builds without a license key; 3.2.0 and 4.x require one) `Image.Load<Rgba32>` with `MaxDegreeOfParallelism = 1` (no decode-into-buffer API, so it allocates its image each call).

## Machine

- CPU: AMD Ryzen 7 5800X
- OS: Microsoft Windows 10.0.26200 (X64)
- .NET: .NET 10.0.11 (win-x64), process X64
- Logical processors: 16
- Vector128.IsHardwareAccelerated: True, Vector256.IsHardwareAccelerated: True, Vector512.IsHardwareAccelerated: False
- AVX2: True, AVX-512F: False, BMI2: True
- GC: workstation, non-concurrent; tiered compilation default
- BenchmarkDotNet 0.15.8, Release, x64, out-of-process, 1 launch × 3 warm-up × 9 measured iterations (≥ 200 ms each); all four contestants run back-to-back per file (interleaved order).
