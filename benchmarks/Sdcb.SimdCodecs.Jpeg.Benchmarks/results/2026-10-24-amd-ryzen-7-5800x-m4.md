# M4 — sparse IDCT paths (2026-10-24, AMD Ryzen 7 5800X)

Commit `6d59a00`. DC-only blocks collapse to one constant; blocks whose coefficient rows (or
columns) 4–7 are zero run half of the column (or row) pass. Both are bit-identical to the full
transform (exhaustive over all 65 536 DC values; float bits for every last-coefficient index).
Every file below decodes **identical** to the M0 baseline.
