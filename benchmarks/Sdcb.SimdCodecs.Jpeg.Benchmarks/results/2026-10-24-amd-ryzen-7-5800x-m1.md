# M1 — MCU-row streaming (2026-10-24, AMD Ryzen 7 5800X)

Commit `54ef398`. Each MCU row now goes entropy → IDCT → a two-MCU-row strip per
component → RGBA rows immediately; progressive and multi-scan baseline frames keep
their coefficients and run the same row pipeline at the end. No sample arithmetic
changed: every file below decodes **identical** to the M0 baseline.
