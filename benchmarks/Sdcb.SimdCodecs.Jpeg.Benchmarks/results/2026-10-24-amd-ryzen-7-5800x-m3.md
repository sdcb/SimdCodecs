# M3 — entropy decoding (2026-10-24, AMD Ryzen 7 5800X)

Commit `493f457`. 64-bit bit reader with 8-byte refills, 10-bit combined Huffman lookup,
bit state in locals per block, mask-driven progressive refinement over zig-zag-ordered
coefficients. Every file below decodes **identical** to the M0 baseline; quantized
coefficients are identical to libjpeg-turbo on all 246 accuracy files (1.76 × 10⁹
coefficients, 0 mismatches).

## Where the progressive time was (instrumented, not sampled)

Stopwatch around each scan kind, `420-q75-3mp-prog/landscape-almsee`, before the
progressive rewrite: DC first 1.2 ms, DC refine 0.6 ms, AC first 1.7 ms, **AC refine
16.8 ms**, output 2.5 ms (+ IDCT/colour). Walking every band position per block in the
refinement scans was the cost; the non-zero bitmask removes it.
