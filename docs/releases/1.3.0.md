# 1.3.0

1.3 completed the WebP encoder family and expanded animation and transparency support.

## Highlights

- Added WebP lossless encoding with transform selection and predictor-cost optimisation.
- Added WebP lossy encoding, including alpha-plane transparency and tuned rate-distortion behaviour.
- Added WebP animation encoding and improved animated-frame alpha blending to match the reference decoder.
- Added WebP encode benchmarks for speed, output size, quality, peak memory, lossy alpha, and animation modes.
