# 1.2.0

1.2 added compact raster formats and brought them into the facade.

## Highlights

- Added `Sdcb.SimdCodecs.Qoi` for Quite OK Image decoding and encoding.
- Added `Sdcb.SimdCodecs.Pnm` for Netpbm formats and their stream operations.
- Registered QOI and Netpbm in the facade with smoke tests, benchmarks, and SIMD-tier coverage.
- Added samples and documentation for the new formats.
