# 2.0.0

2.0 introduced the current public abstraction and facade design across the codec packages.

## Highlights

- Renamed the facade to `ImageCodecs` and added registration-based decode and encode dispatch with typed options, metadata, planar output, and frame sessions.
- Added the common `IImageDecoder` and `IImageEncoder` contracts, pixel formats and conversion APIs, orientation transforms, scaling, regions, and one-call decode operations.
- Added facade encoder adapters for JPEG, PNG, WebP, TIFF, BMP, ICO, GIF, QOI, and Netpbm.
- Added native region and scale decode paths for JPEG, PNG, WebP, and HEIF, with the box downscaler as the general fallback.
- Added encoder input format contracts, 16-bit input support, metadata handling, and migration guidance for applications moving from the 1.x APIs.
- Established public API baselines for every shipped package and expanded AOT, wasm, oracle, fuzz, and benchmark validation.
