# 1.1.0

1.1 added complete BMP and ICO/CUR support to the codec family.

## Highlights

- Added `Sdcb.SimdCodecs.Bmp` with DIB decoding and encoding across the supported bit depths, palettes, RLE, and stream output.
- Added `Sdcb.SimdCodecs.Ico` for icon and cursor decoding and encoding.
- Added BMP and ICO benchmarks, smoke tests, decode corpora, oracle coverage, and SIMD-tier validation.
- Improved BMP palette handling and 5-6-5 encoding performance, and rejected invalid PNG depth and colour-type combinations.
