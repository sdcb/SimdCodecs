# 1.0.0

The first stable release of SimdCodecs introduced pure-managed image codecs and the initial codec package set.

## Highlights

- JPEG, PNG, WebP, GIF, TIFF, JPEG 2000, JBIG2, HEIF, BMP, ICO/CUR, QOI, and Netpbm decoders were available through dedicated packages and the facade where supported.
- The project established SIMD and scalar implementations, exact oracle tests, fuzz coverage, benchmarks, and NativeAOT and browser-wasm compatibility checks.
- Metadata, pixel conversion, frame handling, scaling, regions, and stream-based decode APIs formed the initial Abstractions contract.
