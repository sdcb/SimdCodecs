# 1.4.0

1.4 delivered the HEIF decoder milestone and broadened container and metadata support.

## Highlights

- Added the decode-only `Sdcb.SimdCodecs.Heif` package with ISOBMFF parsing and an in-repo HEVC intra decoder.
- Added byte-exact HEIF oracle coverage, fuzzing, benchmarks, NativeAOT and Mono AOT smoke tests, and explicit facade registration.
- Added vectorised HEVC inverse transform, SAO, intra prediction, colour conversion, and tiled output paths.
- Added TIFF BigTIFF, JPEG-compressed pages, palette, CMYK, YCbCr, ExtraSamples, Exif, XMP, region, and band decoding support.
- Added APNG decoding and encoding, JPEG 2000 channel definitions, and broader documentation and samples.
